API Docs & cURL

      
All endpoints accept multipart uploads, image URLs, or base64 — use whichever fits your situation. Auth: Authorization: Bearer <API_KEY>.

      

      

      

        
Response formats

        
Default response is JSON containing a download URL — files are NOT stored on your VPS in tmpfiles mode. Use response_format=b64_json for inline base64, response_format=raw for raw bytes, or ?redirect=1 / response_format=redirect with curl -L -o file.png for a direct download. /v1/images/* always returns JSON (with both url and b64_json).
